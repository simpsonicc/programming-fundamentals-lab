## IPO Chart

| Input | Processing | Output |
| :--- | :--- | :--- |
| quantity, price per item, discount percentage, tax percentage | 1. Initialise amount, subtotal, and final bill by 0. <br> 2. Check if any of the input values are less than 0 or the discount percentage is greater than 100. Output errors msg. <br> 3. calculate s, t, a: <br> s = q x p <br> a = s - ((s-d)/100) <br> t = a + ((axt)/100) | Output total amout. |

## PAC Chart

| Given Data | Processing required | Output required |
| :--- | :--- | :--- |
| quantity, price per item, discount percentage, tax percentage. | subtotal = quantity x price <br> amont = subtotal - (subtotal discounted amont)/100) <br> final bill = amont + ((amont x tax percentage)/100) | total amont that needs to be paid. |
